# Neon Brick Odyssey
A self-contained neon arcade brick breaker made with Python and Pygame.

## Run
**Windows:** Double-click `START_GAME.bat` (Python 3.9+ must be installed).

**macOS/Linux:** Run `bash start_game.sh` from the project folder.

On first launch, `main.py` automatically installs Pygame using pip if it is missing. Internet access is required only for that initial install. Python itself must already be installed. On Linux, graphical/audio system libraries may be required depending on your distribution.

## Controls
- Move mouse to move paddle; keyboard left/right when mouse is outside window.
- Click or Space to launch balls and start/advance rounds.
- P pause/resume, R restart, Esc return to title.

## Features
Procedural glowing neon visuals, animated starfield, particle effects, multiple ball physics, five collectible power-ups (wide paddle, multiball, shield, slow-motion, magnet), combo scoring, progressively tougher brick waves, and persistent high score saved in your home folder.

No image, sound, or other game assets are required.
